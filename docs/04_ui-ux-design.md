## 1. UI/UX 설계 목표

One Page는 **기록하는 즐거움**과 **다시 꺼내보는 감성적인 경험**을 제공하는 것을 목표로 한다.

사용자가 복잡한 기능을 배우지 않아도 직관적으로 사용할 수 있도록 설계하며, 콘텐츠가 주인공이 되는 UI를 지향한다.

## 2. 디자인 컨셉

### 키워드

Minimal · Emotional · Calm · Clean · Diary

### 핵심 UX 원칙

- 하루 기록은 1분 안에 작성할 수 있어야 한다.
- 사용자의 글과 사진이 가장 눈에 띄어야 한다.
- 불필요한 버튼과 메뉴를 최소화한다.
- 다크모드를 기본으로 고려한다.
- 부드러운 애니메이션으로 감성을 더한다.

- 충분한 명암 대비
- 반응형 레이아웃 지원

## 11. UI 설계 원칙

- 콘텐츠 중심의 인터페이스를 제공한다.
- 사용자가 최소한의 클릭으로 일기를 작성할 수 있도록 한다.
- 감성적인 분위기를 유지하면서도 정보 전달력을 해치지 않는다.
- 모든 주요 기능은 3번 이하의 클릭으로 접근 가능하도록 설계한다.
- 일관된 컴포넌트와 컬러 시스템을 유지하여 사용성을 높인다.
