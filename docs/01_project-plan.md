## 1. 프로젝트 개요

### 1.1 프로젝트 소개

**One Page**는 하루의 기억을 한 페이지로 기록하는 감성 다이어리 웹 서비스이다.

사용자는 하루 동안 있었던 일과 감정, 사진, 음악 등을 기록할 수 있으며, AI가 하루를 자연스러운 문장으로 요약해 준다.

시간이 지난 후 과거의 기록을 다시 돌아보며 자신의 성장과 추억을 회상할 수 있는 서비스를 목표로 한다.

### 1.2 개발 목적

- React 기반 SPA 개발 경험
- Node.js REST API 설계 및 구현
- MariaDB 데이터베이스 설계
- JWT 기반 인증 구현
- 파일 업로드 기능 구현
- AI API 연동 경험
- Docker 기반 배포 환경 구축
- GitHub 기반 프로젝트 관리 및 문서화

> 기술 스택 및 개발 환경의 상세 내용은 [05_dev-guide.md](./05_dev-guide.md) 참조

### 1.3 사용자

**일반 사용자** — 회원가입 후 서비스를 이용하는 사용자

관리자 및 다중 권한 개념은 본 버전에서 다루지 않는다.

## 3. 기능 상세

### F-001 회원가입

사용자가 이메일 계정을 생성한다.

**입력** · 이메일 / 비밀번호 / 비밀번호 확인 / 닉네임

**처리**

- 이메일 중복 검사
- 닉네임 중복 검사
- 비밀번호 BCrypt 암호화
- 회원 정보 저장

**결과** · 회원가입 완료 후 로그인 화면으로 이동

### F-002 로그인

**입력** · 이메일 / 비밀번호

**처리**

- 사용자 인증
- JWT Access Token 발급
- Refresh Token 저장
- 자동 로그인 처리

**결과** · 메인 화면 이동

### F-003 로그아웃

**처리** · Access Token 삭제 / Refresh Token 삭제

**결과** · 로그인 화면 이동

### F-004 프로필 관리

- 닉네임 변경
- 프로필 이미지 변경
- 비밀번호 변경

### F-005 일기 작성

**입력**

| 항목 | 필수 여부 |
|---|---|
| 제목 | 선택 (미입력 시 AI 추천) |
| 내용 | 필수 |
| 감정 | 필수 |
| 사진 | 선택 (최대 3장) |
| 음악 | 선택 |
| 위치 | 선택 |
| 태그 | 선택 |

**처리** · 데이터 저장 → AI 요약 생성 → 작성일 저장

**결과** · 일기 생성 완료

### F-006 일기 조회

**조회 조건** · 날짜(일별) / 월별 / 연도별 / 태그 / 검색어

**결과** · 일기 목록 반환

### F-007 일기 수정

작성자가 기존 내용을 수정한다.

**수정 가능 항목** · 제목 / 내용 / 사진 / 감정 / 음악 / 위치 / 태그

### F-008 일기 삭제

Soft Delete 방식으로 처리한다.

휴지통으로 이동 후 30일 뒤 자동 삭제

### F-009 사진 업로드

**지원 형식** · JPG / PNG / WEBP

**제한** · 최대 3장, 장당 10MB 이하

### F-010 음악 기록

**입력 방식** · Spotify URL / YouTube URL / 직접 입력

**저장 항목** · 제목 / 아티스트 / 링크

### F-011 태그 관리

사용자가 자유롭게 태그를 추가한다.

예시 · 공부 / 여행 / 가족 / 운동

### F-012 검색

**검색 대상** · 제목 / 내용 / 태그 / 위치

**정렬** · 최신순 / 오래된순

### F-013 AI 하루 요약

**입력** · 일기 내용

**처리** · LLM에게 요약 요청

**결과** · 한 문단 요약 생성

> 오늘은 새로운 기술을 배우며 성장한 하루였습니다.

### F-014 AI 제목 추천

**조건** · 제목이 비어있는 경우

**처리** · AI가 제목 생성

> 새로운 시작

### F-015 월간 리포트

**생성 항목**

- 감정 비율
- 가장 많이 사용한 단어
- 가장 많이 방문한 장소
- 작성 횟수

### F-016 연간 리포트

**생성 항목**

- 총 기록 수
- 연속 기록
- 행복 비율
- AI 연간 회고

한 해를 하나의 이야기처럼 요약하여 제공한다.

### F-017 통계

**제공 정보**

- 총 일기 수
- 연속 작성 일수
- 총 사진 수
- 총 태그 수
- 가장 많이 사용한 감정

### F-018 타임캡슐

**입력** · 공개 날짜 (예: 6개월 후 / 1년 후)

**처리** · 해당 날짜까지 잠금

**결과** · 공개 전에는 열람 및 수정이 불가능하다.

## 6. 비기능 요구사항

### 6.1 성능

- 페이지 응답 시간 2초 이하
- API 평균 응답 시간 500ms 이하

### 6.2 보안

- JWT 인증
- BCrypt 비밀번호 암호화
- SQL Injection 방지
- XSS 방지
- 입력값 검증

### 6.3 사용성

- 반응형 웹 지원 (Desktop / Tablet / Mobile)
- 다크 모드 지원
- 직관적인 UI 제공

### 6.4 유지보수

- RESTful API 설계
- 환경 변수 분리
- Docker 기반 실행 환경

## 10. 프로젝트 목표

본 프로젝트는 단순한 CRUD 다이어리 서비스를 구현하는 것이 아니라, AI와 감성적인 사용자 경험을 결합하여 **기억을 기록하고, 시간이 지난 후 다시 꺼내볼 수 있는 디지털 추억 저장소**를 만드는 것을 목표로 한다.

또한 실제 서비스 개발 과정을 경험하며 프론트엔드, 백엔드, 데이터베이스, AI 연동, 배포까지 전 과정을 학습하고 포트폴리오로 활용하는 것을 최종 목표로 한다.
